# CTF Lab Landing Page

صفحة هبوط عربية/RTL لمنصة CTF مع أقسام كاملة، نموذج تواصل، وجدول فعاليات.

## التشغيل محلياً

### باستخدام Python
```bash
python -m http.server 8000
```
ثم افتح المتصفح على: `http://localhost:8000/index.html`

### باستخدام npm
```bash
npm install
npm run start
```

> ملاحظة: لا توجد تبعيات خارجية، الهدف فقط تشغيل خادم بسيط محلياً.

## ملاحظات
- تم تصميم الصفحة لتعمل بدون أي إعدادات إضافية.
- في حال أردت تغيير تاريخ العد التنازلي، عدّل قيمة `data-target` في عنصر العد التنازلي داخل `index.html`.
